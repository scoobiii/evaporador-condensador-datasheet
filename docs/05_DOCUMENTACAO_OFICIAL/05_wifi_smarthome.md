# Documentação oficial — Wi‑Fi e SmartHome

A página oficial do produto classifica o equipamento como conectado e informa recursos de conectividade associados ao ecossistema Midea [1]. A página institucional Casa Inteligente descreve o aplicativo SmartHome como meio de controle de eletrodomésticos conectados [2].

A presença física do módulo **EU-SK105** foi observada nas fotos do projeto, com registro Anatel **071398-21-05648**. O código do módulo, por si só, não documenta uma API local, MQTT, protocolo serial, pinagem ou lista completa de variáveis.

Até que a Midea publique a interface aplicável ao modelo, o projeto deve usar somente os estados expostos oficialmente pelo aplicativo ou por documentação autorizada. A captura de tráfego, tentativa de comandos não documentados ou injeção no barramento não faz parte da etapa atual.
