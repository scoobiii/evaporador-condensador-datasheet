# Documentação oficial — operação

O manual oficial descreve a operação normal, operação manual de emergência, controle remoto, mensagens do display, filtros, limpeza e funções como turbo, dormir, siga-me, timer, LED e clean [1].

Para o projeto de telemetria, os campos de usuário devem ser tratados como **estado operacional observado** quando obtidos por interface documentada: ligado/desligado, modo, temperatura ajustada, velocidade do ventilador, timer, funções especiais e código exibido. Esses campos não comprovam corrente do compressor, pressão do refrigerante ou temperatura de descarga.

A manutenção deve preservar as condições de segurança do manual. A coleta de dados não pode bloquear o controle remoto, alterar parâmetros originais ou substituir proteção elétrica e térmica.
